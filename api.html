NYTRO REST API

Verwalte Guilds, Module und Events programmatisch. Base URL: https://api.nytro.bot/v1

Authentifizierung

Alle Requests benötigen einen Bearer Token (OAuth2 oder API-Key).

Authorization: Bearer mtok_dein_access_token

Guild Endpoints

GET /guilds

Liste aller Guilds, in denen der Bot ist und der User Zugriff hat.

{ "guilds": [ { "id": "123456789012345678", "name": "NYTRO HQ", "member_count": 12412, "modules": ["mod", "tickets", "level"] } ] }
GET /guilds/{guild_id}

Details einer einzelnen Guild inkl. Modul-Status.

PUT /guilds/{guild_id}/modules/{module}

Modul aktivieren/deaktivieren (mod, tickets, leveling, logging, …).

// Body { "enabled": true, "config": { ... } }
GET /guilds/{guild_id}/stats

Statistiken: Commands, Tickets, Mod-Aktionen, Level-Ups.

OAuth & Callback

GET /oauth/authorize

Discord OAuth2 Authorize URL. Redirect URI: https://nytro.bot/callback

https://discord.com/api/oauth2/authorize? client_id=CLIENT_ID &redirect_uri=https://nytro.bot/callback &response_type=code &scope=identify%20guilds
POST /oauth/token

Tauscht den Authorization Code gegen Access + Refresh Token.

GET /callback

Frontend Callback-Seite. Empfängt ?code= und ?state= von Discord.

Webhooks / Events

POST /webhooks/{guild_id}

Webhook registrieren für Events (ticket.create, mod.action, level.up, …).

Rate Limits

120 Requests / Minute pro Token. Bei Überschreitung: HTTP 429 mit Retry-After Header.
