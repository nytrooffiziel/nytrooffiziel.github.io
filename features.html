Features

Alles, was NYTRO für deinen Discord-Server mitbringt – übersichtlich und modern.

🛡️

Auto-Moderation

Wortfilter, Anti-Spam, Invite-Filter, Mass-Mention-Schutz und KI-gestützte Erkennung von Toxizität.

🚨

Anti-Raid & Anti-Nuke

Schutz vor Massen-Joins, Rollen-Löschungen und Channel-Zerstörung. Whitelist & Alarm-Button.

🎫

Ticket-System

Kategorien, Transcripts, Bewertungen, Claim-System und private Support-Channels.

⭐

Leveling & XP

XP für Nachrichten und Voice, Ränge, automatische Rollen und Leaderboards.

📝

Umfangreiches Logging

Nachrichten, Rollen, Channels, Bans, Kicks, Joins/Leaves und Voice-Events loggen.

⚙️

Web-Dashboard

Alle Einstellungen live im Browser – hellblaues, modernes UI ohne Commands.

🔌

REST API

Guilds, Module und Stats programmatisch steuern. OAuth2 + API-Keys.

🔗

Webhooks & Callbacks

Events an deine eigenen Server senden. OAuth Callback für nahtlose Anmeldung.

🌍

Mehrsprachig

Deutsch, Englisch und weitere Sprachen. Jede Nachricht anpassbar.
