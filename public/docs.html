Setup, Commands, OAuth & Dashboard

1. Setup

  1. Discord Application erstellen → Developer Portal
  2. Bot erstellen, Token kopieren, Message Content Intent aktivieren
  3. OAuth2 → Redirect: http://localhost:3000/callback
  4. .env.example nach .env kopieren und ausfüllen
  5. npm install && npm start

2. Bot Commands (Prefix: n!)

n!help – Hilfe n!ban @user [grund] – Bannen n!kick @user [grund] n!mute @user [min] [grund] n!unmute @user n!warn @user [grund] n!warnings @user n!purge <1-100> n!ticket [betreff] – Ticket öffnen n!ticketsetup – Button-Panel n!close / n!claim n!rank / n!leaderboard n!setmodlog #channel n!setprefix ! n!modules / n!module <name> on|off n!userinfo / n!serverinfo / n!ping

3. OAuth & Admin-Filter

Nach dem Login lädt das Dashboard alle Guilds des Users von Discord. Es werden nur Server angezeigt, bei denen das Permission-Bit ADMINISTRATOR (0x8) gesetzt ist oder der User Owner ist. Zusätzlich wird geprüft, ob der Bot auf dem Server ist.

4. Dashboard API

GET /api/me GET /api/guilds – nur Admin-Server GET /api/guilds/:id – Settings, Module, Channels… POST /api/guilds/:id/settings POST /api/guilds/:id/modules/:module POST /api/guilds/:id/automod POST /api/guilds/:id/levelrole

5. Module

moderation · tickets · leveling · logging · automod · welcome
Alle Module können per Command oder Dashboard ein-/ausgeschaltet werden.
