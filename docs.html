OAuth, Guilds, Callback und Client Libraries für die NYTRO API.

🔐 OAuth2 Flow

  1. User klickt „Mit Discord anmelden“
  2. Redirect zu Discord Authorize URL mit client_id, redirect_uri, scope=identify guilds
  3. Discord leitet zurück auf /callback?code=…&state=…
  4. Frontend oder Backend tauscht Code gegen Token via POST /oauth/token
  5. Access Token speichern und für API-Calls verwenden
// Beispiel Redirect URI https://nytro.bot/callback

🏠 Guild Management

Nach der Anmeldung kann der User alle Guilds sehen, in denen er Admin-Rechte hat und der Bot vorhanden ist.

// GET /guilds fetch('https://api.nytro.bot/v1/guilds', { headers: { 'Authorization': 'Bearer ' + token } }) .then(r => r.json()) .then(data => console.log(data.guilds));

🔗 Callback Handling

Die Callback-Seite nimmt den code entgegen und leitet den User ins Dashboard.

// Pseudo-Code (Frontend) const params = new URLSearchParams(window.location.search); const code = params.get('code'); const state = params.get('state'); // Code an Backend senden → Token erhalten // Dann: localStorage setzen + redirect /dashboard

📦 Client Libraries

Offizielle und Community-Libraries für die NYTRO API.

JavaScript / Node.js

npm install nytro-api // Usage const { NytroClient } = require('nytro-api'); const client = new NytroClient({ token: 'mtok_…' }); const guilds = await client.guilds.list(); await client.guilds.setModule('123…', 'tickets', { enabled: true });

Python

pip install nytro # Usage from nytro import NytroClient client = NytroClient(token="mtok_…") guilds = client.guilds.list()

discord.js Integration (Beispiel)

// In deinem Bot const { Client } = require('discord.js'); // NYTRO Webhooks empfangen und verarbeiten app.post('/nytro-webhook', (req, res) => { const event = req.body; if (event.type === 'ticket.create') { // Ticket-Channel erstellen etc. } res.sendStatus(200); });
